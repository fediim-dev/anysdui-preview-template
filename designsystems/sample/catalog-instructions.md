Exactly one component has the id root; other ids are snake_case names of letters, digits and underscores that say what the component is (email_field, submit_button). A container lists its children as an array of ids in content. Bind a value with {"@path": "/form/email"} (RFC 6901, leading slash) and send the data in updateDataModel; DsTextField writes back to the path bound to value, is editable only when value is a path, and needs a label. DsButton takes its label as a child DsText and its handler as onClick: {"event": {"name": "submit"}}. Use DsText for all text and DsIcon for icons; give a meaningful DsIcon an accessibility.label. Style with theme tokens, never literal colors: write {"type":"color","value":"primary"} and {"type":"typography","value":"title"}, not "#6750A4". Leave light and dark to the host, or call setThemeMode. Pick a component's preset look with its variant property (DsButton). Send a theme only in createSurface or with setTheme, never inside a component; animate only through the theme's motion section.
